# פריסה חד־פעמית

1. פותחים את גיליון הנתונים: https://docs.google.com/spreadsheets/d/1_bTvTExdAyWi45wJ9QKHY1RS5euLGYGKlwaoaSAuUmw/edit
2. Extensions → Apps Script ומדביקים את `apps-script.gs`.
3. Deploy → New deployment → Web app; Execute as: Me; Who has access: Anyone.
4. מעתיקים את כתובת `/exec` ומחליפים את `PASTE_APPS_SCRIPT_WEB_APP_URL_HERE` ב־`index.html`.
5. מפרסמים את התיקייה `mobile-course-survey` ב־GitHub Pages.
