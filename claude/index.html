Capstone: prove mastery by building a real AI system

After watching the path, do one integrated project. Do not just consume the videos. Build a working workflow that uses Claude as a professional partner.

  1. Create a Claude Project with instructions and reference files.
  2. Build one Artifact that solves a real problem.
  3. Use Claude Code to create or improve a small repo.
  4. Add one connector or MCP tool with clear permissions.
  5. Delegate work to Cowork or a subagent and review the result.
  6. Write a final SOP so the workflow can be repeated.
Professional standard
  • Every output has a clear goal and acceptance criteria.
  • Claude gets the right context before acting.
  • Tools have permission boundaries.
  • Important actions require review or approval.
  • Claims are verified, not blindly trusted.
  • The workflow is documented so it can run again.
